# Visual identity

The project and package name is **pi-last-words**. The display wordmark is **last words**, with a small Pi host badge above it.

- English tagline: **Work first. Words last.**
- Direction: a restrained score-title composition, with flowing italic lettering and an original musical closing fragment.
- Main ink: `#272622`; secondary text: `#68665f`.
- The Pi badge uses the official light-scheme color, `#111111`, and its original geometry.

## Assets

| File | Purpose |
| --- | --- |
| `logo.svg` | Standalone wordmark with text converted to vector outlines |
| `logo.png` | White-background 2880 × 912 wordmark for README and package previews |
| `icon.svg` | The project's own outlined `lw` monogram and score-ending mark |
| `icon.png` | Transparent 512 × 512 project icon |
| `logo-source.svg` | Editable wordmark; uses Cochin Italic and Optima |
| `icon-source.svg` | Editable project icon; uses Cochin Italic |
| `pi-badge.svg` | Unmodified upstream Pi badge retained as the source reference |

The wordmark and project icon are designed for light backgrounds. The exported SVGs have no font-file or network dependencies. The editable source files require the named fonts for faithful regeneration; no font software is bundled.

The independent project icon is not the Pi badge. Keep the host mark subordinate to `last words`, and retain the full project name in package metadata and README headings.

## Upstream mark and attribution

The Pi badge comes from the official [Pi Press Kit](https://pi.dev/press-kit), which provides it as a square mark for favicons and compact badges:

- Original SVG: <https://pi.dev/favicon.svg>
- Upstream project: <https://github.com/earendil-works/pi>

The badge identifies the host ecosystem. Its use does not imply that this extension is an official Pi product or endorsed by the Pi maintainers. The Pi mark remains an upstream brand asset, not a logo claimed as this project's own.

The score fragment was drawn for this project; it is a stylized closing motif, not a playable score excerpt or a copy of an existing composition.
